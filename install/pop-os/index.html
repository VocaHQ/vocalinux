Pop!_OS Setup Guide

Install Voice Dictation on Pop!_OS

Pop!_OS uses Ubuntu's own version numbering, and 24.04 and newer meet the Python 3.11 floor. The install script detects Pop!_OS as part of the Ubuntu family.

Install command

curl -fsSL https://raw.githubusercontent.com/VocaHQ/vocalinux/main/install.sh -o /tmp/vl.sh bash /tmp/vl.sh

Prerequisites

  • Pop!_OS 24.04 or newer
  • Python 3.11+ with the distro's python3-gi (the installer handles this)
  • Working microphone
  • curl installed (sudo apt update && sudo apt install -y curl)

Supported on

  • Pop!_OS 24.04 and newer: good support

Support levels come from the project’s distribution compatibility matrix. They describe expected compatibility, not a list of test machines.

Other install options for Pop!_OS

Native .deb package

Download the .deb for your CPU from GitHub Releases (arm64 files are attached too). It is a thin package: Python and GTK come from the distro, whisper.cpp runs on the CPU, and there is no auto-update. On Wayland, add yourself to the input group (sudo usermod -aG input $USER, then log out and back in) or the default hotkey stays off.

sudo apt install ./vocalinux_*_amd64.deb

Flatpak from the VocaHQ remote

Not on Flathub. The self-hosted vocahq remote updates with flatpak update and ships whisper.cpp only.

flatpak install https://vocahq.github.io/vocalinux-flatpak/com.vocalinux.Vocalinux.flatpakref

Compare every package format on theinstall overview, or read theFlatpak guide.

Setup notes for Pop!_OS

  1. For a manual install, use libgirepository-2.0-dev if libgirepository1.0-dev is not available.
  2. The install script adds you to the input group for Wayland hotkeys; log out and back in afterwards.
  3. If the hotkey or typing does not work in your session, enable Settings → Shortcuts → External Activation (Desktop Shortcut) and bind a desktop shortcut to vocalinux --toggle (toggle only, no push-to-talk), or dictate into the Dictation Pad and copy the text out.
  4. whisper.cpp uses a Vulkan GPU when available; check with vulkaninfo --summary.

Post-install checklist

  • Run vocalinux --version to confirm the installed release.
  • Launch vocalinux and confirm the tray icon appears. On GNOME, the tray needs the AppIndicator extension.
  • Hold Right Alt (Option) to dictate, or switch to toggle mode in Settings → Shortcuts, and confirm text lands in a terminal and a browser.
  • If anything misbehaves, run vocalinux --debug and check the troubleshooting guide.
