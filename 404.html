HTTP 404 · No such file or directory

This page is not in your $PATH.

The link is broken, the page moved, or the URL picked up a typo on the way here. Vocalinux can type what you say, but it can't type a page that doesn't exist.

Fun facts about 404

chmod 404

r-- --- r--. Owner and others can read, the group gets nothing, and nobody can write. Fitting for a page that isn't there.

exit 404

Exit statuses are 8 bits, so a shell reports $? = 148 (404 mod 256). Even the error code got truncated.

0x194 · 0o624 · 0b110010100

404 in hex, octal and binary. None of them is a valid URL on this site either.
