VocaHQ Flatpak remote

Self-hosted, signed OSTree repository for Vocalinux — published on every stable tagged release, so installs auto-update via flatpak update. 

flatpak install __FLATPAKREF_URL__

The .flatpakref adds the vocahq remote and resolves the GNOME runtime through Flathub in one step. To wire it up by hand instead: 

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --if-not-exists vocahq __FLATPAKREPO_URL__
flatpak install vocahq com.vocalinux.Vocalinux

The GNOME runtime still comes from Flathub — the .flatpakref declares RuntimeRepo so flatpak finds it there. Vocalinux itself is not on Flathub.
