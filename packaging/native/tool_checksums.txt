# Pinned build inputs for packaging/native/build.sh.
#
# Same contract as packaging/appimage/tool_checksums.txt: everything the
# package build downloads is pinned and verified here, so two builds of the
# same commit cannot differ.
#
# Columns: name, kind, value, source — parseable by awk.
#
#   sha256   the file downloaded from <source> must hash to <value>
#   docker   build inside image <value>; <source> records the tag it came from
#   version  recorded for humans; the hash pins pin the artifacts themselves
#
# To bump nfpm: change the version in the <source> URLs, download the
# tarballs, and replace <value> with `sha256sum` of each. The base image
# digest comes from `docker buildx imagetools inspect debian:12` (use the
# index digest, not a per-architecture one — the same line has to work on
# x86_64 and aarch64).
